## 🎯 Problem Statement

In the hospitality industry, decision-making often suffers due to:
- Unpredictable booking patterns  
- High cancellation rates  
- Lack of visibility into revenue drivers  

This project aims to solve these challenges by transforming raw booking data into **actionable insights and an interactive dashboard**.

---

## 💡 Solution Approach

Instead of directly building charts, I followed a structured analytics pipeline:
Raw Data → Cleaning → Structuring → Data Modeling → Analysis → Dashboard

✔ Converted raw data into **analysis-ready format**  
✔ Designed a **star schema data model**  
✔ Built meaningful KPIs for decision-making  
✔ Delivered insights through a clean dashboard  

---

## 🧠 Data Architecture

A well-structured data model was created to ensure scalability and clarity:

### 🔹 Fact Tables
- `fact_bookings`
- `fact_aggregated_bookings`

### 🔹 Dimension Tables
- `dim_hotels`
- `dim_rooms`
- `dim_date`

This approach mimics real-world data warehouse design.
